# Parallax Engine

The engine behind an AI-powered interactive learning platform for New Zealand schools.

Students and teachers ask for a concept. The engine builds an accurate, interactive simulation of it, then lets them reimagine it in different ways (a circuit as water in pipes, or as balls on a hill).

## How it works

- **Truth:** deterministic solvers (circuits, motion, populations). Every number a student sees comes from here, never from an AI model.
- **Lens:** how a concept is drawn and played with. Generated by AI on request, reading Truth's output.
- **Spec:** the structured lesson format the AI writes and the engine checks before anything renders.

## Status

- [x] Circuit Truth solver (`src/engine/truth/circuit`) with 15 passing tests
- [x] Interactive circuit workspace (`/lab/circuits`): drag-and-drop parts, wiring, live current flow, diagnostics, LED challenge, capacitor transients
- [x] Lesson Spec + AI generation (`/lesson`, `src/engine/spec`): the AI writes a structured lesson; the engine validates every circuit with the solver and sends errors back for automatic repair
- [x] AI tutor, text (`/api/tutor`, `src/engine/tutor`): a chat panel in every lesson. The server solves the student's current board with the Truth solver and gives the tutor those readings, so it only quotes real numbers. Readings go in as system messages, so a student can't fake them by typing.
- [ ] AI tutor, voice
- [x] Motion Truth solver (`src/engine/truth/motion`): exact projectiles and ramps, RK4 air resistance, energy tracking, 14 tests

- [x] Motion lessons: the generator picks the engine (circuits, motion or populations) and the validator runs the solver, rejecting challenges that are already solved or that no allowed setting can solve
- [x] Population Truth solver (`src/engine/truth/population`): logistic growth, Lotka–Volterra predators, trapping and harvest campaigns, 9 tests
- [x] Populations lab (`/lab/populations`): habitat view, dual-axis graph with control shading, prey-vs-predator cycle plot, challenges
- [x] Populations lessons: generated, solver-validated and tutored like the other engines
- [ ] Genetics (Punnett squares and inheritance)

## Development

```bash
npm install
npm test
npm run dev
```

The site is behind an "Enter code" screen (`src/proxy.ts`). The code is `ACCESS_CODE` (default `4145`); changing it signs everyone out. The AI routes check it too.

Lesson generation needs an Anthropic API key in `PARALLAX_ANTHROPIC_API_KEY` (or `ANTHROPIC_API_KEY`; Claude Code cloud environments reserve that name, so use the first one there). Without it, `/lesson` still shows a pre-made example lesson, but the tutor won't answer.
